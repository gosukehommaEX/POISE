# POISE 0.1.0

* Initial release.
* `EstRROneStep()`: one-step closed-form negative binomial rate ratio
  estimator with a matching closed-form standard error and Wald inference.
* `EstRRSummary()`: reconstruct the negative binomial maximum likelihood
  rate ratio, standard error, and Wald test from group-level summaries.
* `print.rrfit()`: formatted display for fitted rate ratio objects.
* `GenSimData()`: simulate two-group negative binomial recurrent event data.
* `CompareOC()` and `ReconError()`: simulation utilities for operating
  characteristics and summary reconstruction error.
* `SampleSizeTang()`: sample size for a two-group negative binomial rate
  comparison following Tang (2015).
